# Jarvis Dashboard

Особистий AI-дашборд: листи, план дня, «що горить», база Obsidian, проєкти і голосовий асистент на базі Claude.

**Зараз готово (етап 1):** сервер-ядро, дашборд у стилі макета, справжній чат з Claude з памʼяттю розмови, голосовий ввід через браузер. Листи, календар і проєкти поки демо-дані.

## Встановлення на MacBook (один раз)

1. Встанови Homebrew, якщо його ще нема: інструкція на brew.sh.
2. Встанови Python і Node:
   ```
   brew install python@3.11 node
   ```
3. Візьми API-ключ на console.anthropic.com → API Keys.
4. Розпакуй проєкт у зручну папку, наприклад `~/Projects/jarvis-dashboard`.

## Запуск

```
cd ~/Projects/jarvis-dashboard
./start.sh
```

Перший запуск створить файл `.env` і зупиниться. Відкрий `.env`, встав ключ у `ANTHROPIC_API_KEY=` і запусти `./start.sh` ще раз. Перший раз він ставить залежності й збирає дашборд, це кілька хвилин.

Потім відкрий у браузері **http://127.0.0.1:8765**.

- Пиши в поле під сферою або натисни на сферу і говори (Chrome або Safari).
- Після змін в інтерфейсі: `./start.sh --rebuild`.

## Доступ з iPhone

1. Встанови Tailscale на MacBook і iPhone, увійди в один акаунт.
2. У `.env` постав `HOST=0.0.0.0` і перезапусти.
3. На iPhone відкрий `http://<імʼя-макбука>:8765` (імʼя видно в застосунку Tailscale).

Не відкривай порт у роутері: Tailscale дає доступ тільки твоїм пристроям.

## Розробка інтерфейсу

Два термінали:

```
source .venv/bin/activate && python -m core.main
cd web && npm run dev
```

Дашборд відкривається на http://localhost:5173 і оновлюється одразу після збереження файлу.

## Структура

```
core/            Python-ядро (FastAPI)
  main.py        API, WebSocket, роздача дашборду
  brain.py       розмова з Claude
  dashboard.py   дані для блоків (поки демо)
  db.py          SQLite: історія чату, журнал дій
  connectors/    етап 2+: gmail, calendar, trello, obsidian
web/src/         React-дашборд
  App.jsx        розкладка і чат
  blocks.jsx     блоки: горить, план, листи, Obsidian, проєкти
  Orb.jsx        сфера асистента
voice/           етап 5: перенесений Jarvis
widgets/         етап 7: віджети, які дашборд створює сам
data/            база і токени (не в git)
```

## API

| Метод | Шлях | Що робить |
| --- | --- | --- |
| GET | /api/health | Чи живе ядро і чи є ключ Claude |
| GET | /api/dashboard | Дані для всіх блоків |
| GET | /api/messages | Останні повідомлення чату |
| POST | /api/chat | `{"text": "...", "source": "dashboard"}` → відповідь Claude |
| WS | /ws | Живі події: нові повідомлення з будь-якого джерела |

Голосовий Jarvis на етапі 5 просто шле `POST /api/chat` з `"source": "voice"`, і відповідь зʼявляється на дашборді.
